# 语义支持人工核查规则（judgment_source = human，基于本人核对过的参考答案）

`score.py` 只判断"答案是否等于参考答案""引用 ID 是否在实际输入中""是否覆盖参考证据"，**不判断引用原文是否支持模型结论**。
本文件用以下人工规则，对正式题首次尝试逐条给出语义支持状态：

| 情况 | support_status | 理由 |
|---|---|---|
| 答案正确，且引用覆盖参考证据 | supported | 参考证据原文（本人已核对）支持该结论 |
| 答案为具体值但错误，引用了参考证据 | contradicted | 所引原文推出的是另一个值/选项 |
| 答案为"证据不足"，但参考答案有具体值 | contradicted（对"证据不足"这一主张） | 所引原文足以作答，"证据不足"的主张不成立 |
| 参考答案为"证据不足"，模型也答证据不足，且引用了说明缺失的段落 | supported | 补页明确写出未采集相关数据 |
| 引用未覆盖参考证据（多见于 K） | insufficient | 所引段落不足以支持任一结论 |

据此汇总（正式题 40 次首次尝试）：supported = 答对的 15 次；其余 25 次为 contradicted 或 insufficient。
局限：规则依赖参考答案本身正确；未逐条阅读模型对非参考段落的引用是否含额外支持信息。
